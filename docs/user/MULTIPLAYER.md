# 多人联机模式

多人联机模式是 MAW Multiplayer（基于 MAW 修改的非官方分支）新增的功能，用来给多人游戏实况视频做字幕：每位玩家对应一个样式分组，字幕按分组使用独立的 ASS 样式。数据字段见 [JSON_SCHEMA §1.8](../../JSON_SCHEMA.md#18-multiplayer-多人联机模式maw-multiplayer-扩展可选)，实施进度见[实施计划](../plans/多人联机模式实施计划.md)。

> 当前已完成第 1 阶段：模式开关、12 个样式分组、分组快捷键与 ASS 分组样式导出。三轨同时显示的槽位排版、单块偏移与头像会在后续阶段加入。

## 开启与关闭

在「工程设置 → 字幕轨道」勾选「多人联机」。开关随工程保存，默认关闭。

- 开启时会自动打开「ASS 字幕模式」：分组样式只在 ASS 预览与 ASS 导出中生效。
- 第一次开启时，如果工程带有 ASR 识别的说话人，会按说话人首次出现的顺序自动分到第 1–12 组。之后可随时点「按说话人分配分组」重新分配。
- 关闭后，快捷键、预览与导出全部恢复原样，分组设置仍保存在工程里，再次开启即可继续使用。

## 12 个样式分组

每个分组包含名称、说话人和一整套独立的 ASS 样式（字体、字号、文字色、描边色和粗细、阴影色和距离等，字段与样式库一致）。

- 打开方式：「工程设置 → 字幕轨道 → 分组与样式…」，或在 ASS 样式库窗口左侧的「多人分组」列表中选择。
- 分组样式保存在**工程**中，不改动本机样式库。可以「从样式库载入」现有样式，也可以「另存到样式库」供其他工程使用。
- 「复制样式到」把当前分组的样式复制给另一个分组，再单独微调。
- 位置（对齐与边距）由字幕所在的轨道决定，分组只决定外观。

## 给字幕分配分组

选中字幕后按键：

| 按键 | 分组 |
|---|---|
| `1`–`9` | 第 1–9 组 |
| `0` | 第 10 组 |
| `-` | 第 11 组 |
| `=` | 第 12 组 |

- 只在多人模式开启时生效；关闭时 `1`–`5` / `0` 仍是原来的颜色标记与清除。
- 主轨、叠加轨（轨 2）和副轨（轨 3）的选中字幕都会一起设置；可以撤销。
- 字幕列表左侧的颜色条显示分组颜色和对应按键。
- 没有单独指定分组的字幕按以下顺序自动归组：ASR 说话人映射 → 已有的五色标记（黄 / 绿 / 红 / 紫 / 蓝 → 第 1–5 组）→ 第 1 组。在分组窗口点「选中字幕恢复自动分组」可撤掉手动指定。
- 拆分字幕时两半保持原分组；合并时取最早一条的分组。

## 导出

ASS 导出为每个分组写一行独立样式 `MP01`…`MP12`，字幕事件引用所属分组的样式，事件的说话人字段写分组的「说话人」。开启「字幕显示说话人前缀」时，前缀使用分组说话人名称。

SRT 等其他格式不受多人模式影响。
