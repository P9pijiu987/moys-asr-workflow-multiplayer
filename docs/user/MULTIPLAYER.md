# 多人联机模式

多人联机模式是 MAW Multiplayer（基于 MAW 修改的非官方分支）新增的功能，用来给多人游戏实况视频做字幕：每位玩家对应一个样式分组，字幕按分组使用独立的 ASS 样式。数据字段见 [JSON_SCHEMA §1.8](../../JSON_SCHEMA.md#18-multiplayer-多人联机模式maw-multiplayer-扩展可选)，实施进度见[实施计划](../plans/多人联机模式实施计划.md)。

> 第 1–5 阶段均已完成：模式开关、12 个样式分组、分组快捷键、ASS 分组样式导出，三条字幕轨同时显示与轨间移动，按槽位排版与单块偏移，分组头像的即时预览、实际画面预览与烧录。

## 开启与关闭

在「工程设置 → 字幕轨道」勾选「多人联机」。开关随工程保存，默认关闭。

- 开启时会自动打开「ASS 字幕模式」：分组样式只在 ASS 预览与 ASS 导出中生效。
- 第一次开启时，如果工程带有 ASR 识别的说话人，会按说话人首次出现的顺序自动分到第 1–12 组。之后可随时点「按说话人分配分组」重新分配。
- 开启时会同时打开「允许字幕重叠」（轨 2）和「双语字幕」（轨 3）。如果工程已有双语绑定，会先询问并解除绑定（可撤销）。
- 关闭后，快捷键、预览与导出全部恢复原样，「允许字幕重叠」「双语字幕」两个开关回到开启前的状态；分组设置与三条轨上的字幕仍保存在工程里，再次开启即可继续使用。

## 12 个样式分组

每个分组包含名称、说话人和一整套独立的 ASS 样式（字体、字号、文字色、描边色和粗细、阴影色和距离等，字段与样式库一致）。

- 打开方式：「工程设置 → 字幕轨道 → 分组与样式…」，或在 ASS 样式库窗口左侧的「多人分组」列表中选择。
- 分组样式保存在**工程**中，不改动本机样式库。可以「从样式库载入」现有样式，也可以「另存到样式库」供其他工程使用。
- 「复制样式到」把当前分组的样式复制给另一个分组，再单独微调。
- 位置（对齐与边距）由字幕所在的轨道决定，分组只决定外观。

## 给字幕分配分组

选中字幕后按键：

| 按键 | 分组 |
|---|---|
| `1`–`9` | 第 1–9 组 |
| `0` | 第 10 组 |
| `-` | 第 11 组 |
| `=` | 第 12 组 |

- 只在多人模式开启时生效；关闭时 `1`–`5` / `0` 仍是原来的颜色标记与清除。
- 主轨、叠加轨（轨 2）和副轨（轨 3）的选中字幕都会一起设置；可以撤销。
- 字幕列表显示分组颜色和对应按键：单列行在左侧颜色条上，双列视图在每列左侧色带与按键标记上。
- 没有单独指定分组的字幕按以下顺序自动归组：ASR 说话人映射 → 已有的五色标记（黄 / 绿 / 红 / 紫 / 蓝 → 第 1–5 组）→ 第 1 组。在分组窗口点「选中字幕恢复自动分组」可撤掉手动指定。
- 拆分字幕时两半保持原分组；合并时取最早一条的分组。

## 三条字幕轨

多人模式下有三条可以同时出现的字幕轨，借用编辑器已有的三条字幕：

| 轨道 | 对应的原有字幕 | 波形中的位置 | 字幕列表 |
|---|---|---|---|
| 轨 1 | 主字幕 | 中间一格 | 左列「轨 1」 |
| 轨 2 | 叠加字幕 | 最上一格 | 「叠」开头的行 |
| 轨 3 | 副字幕 | 最下一格 | 右列「轨 3」 |

- 波形每行右侧的 `1` / `2` / `3` 标出各格属于哪条轨。按住 `Ctrl`（macOS 为 `Cmd`）在某一格空白处拖动，就在那条轨上新建字幕。
- 选中字幕后按 `Alt+1` / `Alt+2` / `Alt+3` 移动到轨 1 / 2 / 3；三条轨可以多选一起移动。同一条轨内的字幕不能重叠，目标轨在该时间已有字幕时整体不移动。颜色标记跟随字幕移动；移到轨 3 的字幕不保留表情包。
- 轨 3 在多人模式下独立使用：不和主字幕绑定（绑定相关的快捷键与菜单会提示），主字幕合并时也不会连带合并轨 3。
- 多人模式开启期间不能关闭「允许字幕重叠」和「双语字幕」，以免轨 2 / 轨 3 被隐藏；需要时先关闭多人联机。
- 一个时间点最多同时显示 3 条字幕。

## 画面位置：槽位与偏移

字幕在画面中的位置由**槽位**决定，分组样式里的对齐与边距在多人模式下不再决定位置（左右边距仍用于折行宽度）。

- 默认三个槽位：下（画面高度 92%）、中（82%）、上（72%），数值是字幕块底边的位置。轨 1 默认在下、轨 2 在中、轨 3 在上，字幕块水平居中。
- 选中字幕后按 `Alt+↑` / `Alt+↓` 把它移到更高 / 更低的槽位（只改这几条，不改轨道默认）。`↑` / `↓` 本身仍用于切换主副轨焦点。
- 同一时刻两块字幕落在同一槽位时，先出现的留在槽位，后出现的自动向上让位，不会重叠。
- **单块偏移**：
  - 在 ASS 即时预览上（暂停时最方便）直接拖动字幕块，松开后记一次可撤销的修改；鼠标移到字幕块上会显示移动光标。
  - 当前字幕面板下方的「槽位 / X% / Y%」可以精确设置：X、Y 是占画面宽高的百分比，正数向右 / 向下；「复位」恢复轨道默认槽位并清除偏移。
- 字幕块总是被限制在画面内；单条字幕大到放不下时，预览会提示并不显示该时段。
- 即时预览、ASS 导出和实际画面预览使用同一份排版结果：导出的每条字幕都带 `\an2\pos(x,y)`。

## 头像

每个分组可以设置一张头像，字幕前（或后、上方）显示说话人头像。

- 打开方式：「工程设置 → 字幕轨道 → 头像…」，或在样式库窗口的分组页点「头像…」。
- 左侧选择「全局默认」或某个分组。分组页可以「选择头像图片…」（PNG / JPG / WebP / GIF）或「移除头像」。图片导入时最长边缩放到 512 像素并保存在工程里，便携版也能使用。
- 可调项：
  | 项目 | 说明 |
  |---|---|
  | 位置 | 文字左侧 / 右侧 / 上方 |
  | 与文字间距 | 按字号倍数 |
  | 大小 | 按字号倍数（头像为正方形，非正方形图片居中裁切） |
  | 不透明度 | 0–100% |
  | 裁切形状 | 圆形 / 圆角 / 方形；圆角按边长比例 |
  | 图层 | 文字前 / 文字后 |
  | 阴影 | 开关、颜色、不透明度、模糊、X / Y 偏移（按 1080p 像素，导出按分辨率换算） |
- 全局默认作用于所有分组；分组页勾选某项的「覆盖」才单独设置该项，未勾选的项跟随全局默认。
- 排版：头像和文字作为**一个整体**在槽位上居中。头像在左时文字左对齐、紧贴头像右侧；头像在右时文字右对齐、紧贴头像左侧；头像在上时文字居中、在头像下方。这样即使浏览器与最终渲染的字宽略有差异，也只会让整体略微偏移，头像与文字的间距始终准确。
- 拖动字幕块时，按住头像也能拖动整块。头像随字幕一起淡入淡出。
- 关闭头像窗口时会清理不再使用的头像图片；在本次编辑中撤销仍能找回。
- 即时预览（ASS 字幕模式）直接在画布上绘制头像；实际画面预览与烧录见下文。

## 导出

ASS 导出为每个分组写一行独立样式 `MP01`…`MP12`，字幕事件引用所属分组的样式，事件的说话人字段写分组的「说话人」，位置写为 `\pos`。输出方案中的 `\move` 在多人模式下不使用（位置由槽位决定），淡入淡出照常保留。开启「字幕显示说话人前缀」时，前缀使用分组说话人名称。

SRT 等其他格式不受多人模式影响。

### 头像的实际画面预览与烧录

- 导出的 ASS 末尾带两个自定义节：`[MAW Multiplayer Avatars]`（每个头像的显示时间、位置、大小与样式）和 `[MAW Multiplayer Assets]`（头像图片）。libass 和常见播放器会忽略这两节，所以在其他软件里打开只显示文字。
- 「实际画面预览」（localhost 编辑器）和 Launcher 工具箱的「烧录字幕」读取同一份 ASS，用 Pillow 把头像处理成带透明度、阴影和裁切的图片，再用 FFmpeg 叠加：文字后的头像 → 字幕 → 文字前的头像。头像随字幕淡入淡出（跟随输出方案或单句的 `\fad`）。
- 需要带 libass 的 FFmpeg（与原有 ASS 烧录相同）和 Pillow。从源码运行时用 `uv sync --group build` 安装 Pillow；当前发布包不含 Pillow，缺少时实际画面预览只显示文字并给出提示，烧录会报错而不是生成没有头像的视频。
